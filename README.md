### 🚀 About Me

- 🔭 Currently building **SatQuery** — a hybrid satellite-image question-answering system for Smart India Hackathon '26
- 🧠 Architecture philosophy: *predict what needs perception, calculate what can be calculated* — perception, symbolic computation, and language generation stay separated instead of one model doing everything
- 📖 Also building **CourseC** — an AI-powered LMS/course builder that turns textbooks and PDFs into structured courses and assessments
- ⚡ I ship in stages and gates — every milestone gets verified before the next one starts
- 🌱 Currently deep in dual ConvNeXt-V2 encoders, 44-class CORINE land-cover data, and rasterio pipelines
